# 测试报告 · 向量回填与语义检索升级（P0-1）

- **日期**：2026-08-22
- **范围**：`search_memories` 升级为「向量语义 + 关键词混合检索」；新增老数据向量回填脚本
- **测试类型**：升级前后效果对比（A/B）+ 真实生产库验证 + 回填脚本功能验证
- **结论**：✅ 通过。语义检索生效，老记忆回填后即可被语义命中，降级策略安全。

---

## 1. 升级内容

| 项 | 说明 |
|---|---|
| embedding 服务 | `http://10.10.10.146:8005/v1/embeddings`，模型 `/models/Qwen3-Embedding-8B`（OpenAI 兼容，实测连通） |
| 新增能力 | `search_memories` 由「纯关键词（FTS5 LIKE）」升级为「向量余弦召回 + 关键词混合」，支持 `threshold` 过滤 |
| 新增脚本 | `scripts/backfill-embeddings.js`：为升级前写入的无向量老记忆批量补向量（幂等、批量、dry-run、降级） |
| 数据变更 | `memories` 表新增 `embedding` 列（float32 BLOB，老库自动迁移，回填前为 NULL） |
| 降级策略 | embedding 服务不可用/失败时自动回退关键词检索；`EMBEDDING_ENABLED=0` 可整体关闭 |
