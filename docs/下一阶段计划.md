## 阶段 P0 · AI 化（下一个开发周期，做完才是"AI 记忆库"）

### P0-1 向量语义检索（embedding 召回）

- **目标**：搜"怎么连数据库"能命中"用 psql 连接 PostgreSQL"这类语义相近但无共同词的记忆
- **实现**：OpenAI 兼容 embedding 适配层（指向本地 vLLM `/v1/embeddings`）；`memories` 表加向量列；`search_memories` 升级为「向量召回 + 关键词混合」
- **依赖（需外部确认）**：
  - `10.10.10.146:8000` vLLM 的正确 API key（当前 Bearer 认证全部 401，BR-Agent 的 key 无效）
  - vLLM 需挂载 **embedding 类模型**（如 `Qwen3-Embedding-0.6B` / `bge-m3`）——现有 `/models/Qwen3.5-27B-FP8` 是对话模型，**不能**用于 `/v1/embeddings`
- **降级策略**：embedding 不可用/失败时自动回退关键词检索，不影响现有调用
- **兼容**：`threshold` / `rerank` 参数位已预留，纯增量，agent 零改动

### P0-2 LLM 事实抽取（`infer` 生效）

- **目标**：`add_memory` 时抽事实/实体结构化入库，搜"上次部署踩了什么坑"能精准召回被抽取过的事实
- **实现**：写路径加异步 LLM 调用（用 `/models/Qwen3.5-27B-FP8` 的 `chat/completions` 即可，无需 embedding 模型）；`infer=false` 保持原样
- **注意**：写路径异步化，避免阻塞主流程；注意抽取失败不影响原样入库

> P0 两项共用同一个 OpenAI 兼容 client 层，建议一并落地。embedding 依赖外部模型就绪，可先行做 infer。
