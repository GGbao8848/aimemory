## 阶段 P0 · AI 化（下一个开发周期，做完才是"AI 记忆库"）

### P0-1 向量语义检索（embedding 召回）✅ 已完成

- **目标**：搜"怎么连数据库"能命中"用 psql 连接 PostgreSQL"这类语义相近但无共同词的记忆
- **实现**：OpenAI 兼容 embedding 适配层（`src/embeddings/client.js`，指向 vLLM `/v1/embeddings`）；`memories` 表加 `embedding` 列（float32 BLOB）；`search_memories` 升级为「向量召回 + 关键词混合」（`src/db/repo.js` 的 `getVecCandidates` / `cosineSimilarity`）
- **依赖（已确认）**：`10.10.10.146:8005` vLLM 已挂载 `/models/Qwen3-Embedding-8B`，key `brsys-2026`（OpenAI 兼容格式，已验证）
- **降级策略**：embedding 不可用/失败时自动回退关键词检索，不影响现有调用；`EMBEDDING_ENABLED=0` 可整体关闭
- **兼容**：`threshold` 已生效（向量相似度阈值）；`rerank` 参数位保留

### P0-2 LLM 事实抽取（`infer` 生效）✅ 已完成

- **目标**：`add_memory` 时抽事实/实体结构化入库，搜"上次部署踩了什么坑"能精准召回被抽取过的事实
- **实现**：写路径异步 LLM 抽取事实存 `memories.facts`，向量对「原文+facts」生成（`src/llm/client.js`、`syncFacts`）；`infer=false` 保持原样
- **依赖（已确认）**：`10.10.10.146:8001` chat/completions，模型 `qwen3.8-27b`（LLM_ENABLED=1）
- **注意**：写路径异步化，不阻塞主流程；抽取失败不影响原样入库（已验证）

> P0 两项（embedding 语义检索 + infer 事实抽取）均已落地，共用 OpenAI 兼容 client 层。

### P0-3 messages 批量 + agent/run 作用域 ✅ 已完成

- `add_memory` 支持 `messages[]`：多轮对话 LLM 自动提炼成记忆入库（mem0 核心模式）
- `agent_id` / `run_id` 作用域：记忆按 agent/run 隔离，`search_memories` / `get_memories` 可过滤
- 实现：`memories` 表加 agent_id/run_id 列 + 索引；repo `createMemory`/`listMemories`/`searchMemories` 支持作用域
- 集成验证：对话提炼精准（部署对话→"Node 服务部署到 10.10.10.214:18543，使用 pm2 管理…"）；agent 隔离正确
