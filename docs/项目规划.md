## 战略转向（2026-09-19 用户拍板）：北极星 = 数字分身

> 用户原话：「重新回到项目的起源，我很怀疑现在项目的实用性与成本，什么都想要什么也做不好。
> 什么对我们以后构建数字分身最有用？**这里面的东西记录的应该是"我"的本质**。」

**分析结论（存档，后续会话据此理解所有 E 系列目标）：**

1. 数字分身需要三层记忆：**本质层**（价值观/决策风格/取舍标准/口味/表达方式——少而精）、
   **知识层**（项目/设施/关系的事实——中等）、**经历层**（完整原始历史——巨大）。
2. 现状盘点：约九成机器建在经历层（L0 管道）与知识层（L2）上；**本质层（L3）在饿死**——
   它的输入是压缩后的 L1 摘要，推理过程早已丢失。
3. **主要偏差**：现有提炼 prompt 明确「丢弃寒暄/过程性内容」——对 agent 实用是对的，
   对分身是把本质扔掉。本质藏在决策的理由、被否决的选项、取舍时的措辞里。
4. **L0 原始档案是已拥有的最值钱资产**：只要不丢就是复利（未来更好的模型可重炼）。备份纪律不松。
5. 成本的真实结构：token 便宜，**复杂度注意力贵** → 解法不是砍已建成的（维护费已低），
   而是停止加宽度，把全部新增精力投入本质提炼质量。

**转向纪律**：G7 之外不再新增通用功能项（bug 修复除外）；新工作只进 E 系列（本质线）。
两条写入线的分工不变（后台自动沉淀全覆盖 + MCP 即时强调，消解互斥已闭环）。

## E 系列（本质线——转向后唯一的新增方向）

- [ ] **E1 本质直采线**：新增从 **L0 原文直采**的提炼线（绕过 L1 压缩，过程性内容不再被丢）。
      分身视角 prompt：这段对话暴露了什么决策？被否决的选项和理由是什么？体现了什么偏好/原则/风格？
      产出**决策档案**（决策 + 备选 + 理由）与本质观察 → 落 L3。
      省 token 设计：低频批量（月度级起跑）+ 两段式（便宜模型粗筛高价值段落，精炼只跑高分段）。
      验收：从历史 L0 档案炼出首批决策档案，**用户人工评「像不像我」**——这是唯一验收标准。
- [ ] **E2 L3 语义重组**：kinds 向分身语义演进——`identity`（原则与价值观）/ `style`（表达样本）/
      `decisions`（决策档案），旧 kinds（profile/constraints/lessons）兼容保留读取；
      recall_context 的 kinds 参数、admin 视图、时间推理全部跟随。
- [ ] **E3 风格样本库**：L0 中**用户自己的原话**（user role）按代表性抽样 → style 条目。
      分身「说话像我」必须有原始语料；抽取规则要避免敏感内容入档。
- [ ] **E4 月度本质重炼**：低频批量任务，用当时最好的模型重挖 L0 增量——L0 复利的兑现机制；
      重炼产出走 supersede 双时间轴（旧版本可追溯，「以前以为 vs 现在认为」本身是分身的一部分）。
