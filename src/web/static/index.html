    📦 ZCode 插件安装（推荐）
    
          
    批量接入首选：装插件后 MCP 工具自动注册，agent 还会自动学会"何时该写/查记忆"。替代手动复制 JSON。
    
          
      
            
    1. 获取插件目录：公司局域网 Git 拉取 aimemory 仓库，取其中的 plugin/ 目录（管理员可分发拷贝）
      2. 
            
    2. 添加本地 marketplace：ZCode → Settings → Plugin Management → Discover →「+」→ Add local folder → 指向 plugin/
      3. 
            
    3. 安装并配密钥：安装 aimemory 插件 → 运行 /aimemory-key 按引导填个人密钥 → /aimemory status 验证
      4. 
          
    
          
    插件含 skill（记忆使用准则）与命令 /aimemory、/aimemory-key；安装后 agent 自动把部署经验、踩坑、偏好写入记忆，新任务先检索复用。
