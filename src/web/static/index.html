🔑 接入 Token

一枚 Token 对应一个 agent 客户端（如 zcode / claude-code 各一枚），互不影响、可单独吊销。名称为必填项；明文长期保存，页面随时可查可复制。

    🔌 MCP 配置

    选择一种方式接入：一键复制 JSON，或手动模式按字段填入你的 MCP 客户端（url 指向本服务器内网地址）。

    🔌 MCP 接入步骤
    
          
      
            
    1. 签发 Token：登录后切到「接入 Token」，填写名称（必填）新建一枚；建议为每个客户端分别新建（命名区分），明文可随时复制
      2. 
            
    2. 复制配置：「MCP 配置」里复制完整 JSON（默认含最新一枚 Token 明文），或切「手动模式」按字段复制
      3. 
            
    3. 填入客户端：把 JSON 或字段粘贴到你的 agent 的 MCP 客户端配置（Claude Code / Codex / BR-Agent 自定义连接器…）
      4. 
            
    4. 验证：agent 调用 add_memory 提交一条素材（等 AI 提炼完成后），再到本平台「我的记忆」确认
      5. 
          
    
          
    每个员工 Token 互不可见、数据互相隔离；一名员工可同时持有多枚 Token，按客户端分发、单独吊销。MCP 端点：http://<服务器内网IP>:18543/mcp
    
        
    

        
    
          
    🧰 MCP 工具一览
    
          
      
            
    • add_memory — 提交素材（text / messages），AI 提炼成记忆后入库
      • 
            
    • get_event_status — 查询素材提炼状态（提炼需数秒）
      • 
            
    • search_memories — 语义 + 关键词混合检索（支持中文子串）
      • 
            
    • get_memories / get_memory — 列出 / 查看单条
      • 
            
    • update_memory / delete_memory — 修正 / 删除
      • 
          
    
          
    只暴露这 7 个核心工具；写入自动抽取事实（facts）增强召回。每个员工的记忆互相隔离，同一员工多个 agent 共享一份账本。
